## vohoanganh.github.io

Personal academic website of Anh H. Vo (Võ Hoàng Anh), PhD candidate at Sejong University.
Plain HTML/CSS — no build step. GitHub Pages serves it directly from the default branch.

```
index.html            Home: bio + Selected Papers
publications.html     Full publication list (23)
patents-awards.html   Patents, awards, reviewing
experience.html       Education, experience, skills
datasets.html         Released datasets (copy the commented card template to add one)
assets/css/style.css  Shared styles (navy accent: --accent)
assets/img/anh.png    Portrait
```

Paper links: paste a URL into an empty `href=""`; empty links are hidden automatically.
